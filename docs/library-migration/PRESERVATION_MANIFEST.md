# Preservation Manifest

Domain-specific components this migration must not replace, and why. Each
entry names the invariant a library does not provide and the boundary that
keeps library-sourced data from mutating these components directly.

| Domain-specific component | File(s) | Reason it remains custom | Invariant protected | Library boundary around it | Tests proving the boundary |
|---|---|---|---|---|---|
| Book-scoped cash ledger | `src/trading_research/paper_books/cash_ledger.py` | ADR 0006: LumiBot keys state per runtime process, not per `book_id`; no library provides isolated multi-book reservation accounting | Settled/reserved/available cash split; idempotent `INITIAL_CAPITAL`; audited `CASH_ADJUSTMENT` only | LumiBot/broker output passes through PR 9's normalization layer, then PR 10's reconciliation layer, before ever touching cash state; never written directly | Existing book-isolation tests (ADR 0006 "Step 24"); new reconciliation parity tests added in PR 10 |
| Book-scoped position/lot accounting | `src/trading_research/paper_books/positions.py` | Same as above — FIFO lot consumption and `(book_id, symbol)`/`(book_id, lot_id)` primary keys have no library equivalent | FIFO realized-PnL correctness; no cross-book leakage | Same normalization/reconciliation boundary as cash ledger | Same as above |
| Point-in-time portfolio valuation | `src/trading_research/paper_books/valuation.py` | Fixed price-selection priority (evidence snapshot → most recent at-or-before bar → `SOURCE_UNAVAILABLE`) with staleness flags; a missing price must become `None`, never a fabricated zero | Never leaking a future or current price into a historical snapshot; `PARTIAL_MISSING_PRICE`/`POINT_IN_TIME_UNSAFE` statuses | Not exposed to any library; consumes only already-frozen evidence snapshots | Existing valuation/staleness tests |

## Cross-cutting rule

None of the components above may be made to depend on a library's default
behavior for the invariant listed in its row. A library adopted elsewhere in
this migration may *supply data* to these components (e.g., LumiBot supplies
normalized fills; Riskfolio-Lib supplies advisory allocation weights) but
must never *decide* on their behalf. This mirrors the existing
research/execution boundary already enforced by ADR 0003.
