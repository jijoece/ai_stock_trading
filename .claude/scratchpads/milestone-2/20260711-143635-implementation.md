## Notable bug caught and fixed during self-review
Scorer's per-factor `contribution` originally split pillar weight across the
TOTAL configured factor count (including missing ones), which meant
`total_score` could NOT be exactly reconstructed from the flat
`recommendation_factors` list alone when an optional factor was missing —
violating the hard "score must be reconstructible exactly from stored
factors" requirement. Fixed by splitting weight across AVAILABLE factors
only (missing factors get weight=0, contribution=0) and deriving every
pillar's `weighted_contribution` from the same rounded, stored per-factor
contributions the DB persists — see `reconstruct_total_score_from_factors`'s
docstring in scorer.py for the exact derivation
(`total_score == 50 + 0.5 * sum(all factor contributions)`). Caught by
writing `test_missing_optional_factor_excluded_not_zeroed` and the
integration test's reconstruction assertion before declaring this done —
not by the happy-path tests alone.
